# Lokaler DNS
in AdGuard Home lokle DNS-Einträge anlegen
Um in AdGuard Home lokale DNS-Einträge anzulegen, folgen Sie diesen Schritten:
- Filter -> DNS-Umschreibungen
- Auf "Hinzufügen" klicken
- Im Feld "Domain" den gewünschten Domainnamen eingeben (z.B. "meinlokalerhost.local")
- Im Feld "IP-Adresse" die entsprechende IP-Adresse von Nginx eingeben (z.B. "192.168.1.1")
- Auf "Speichern" klicken, um den Eintrag zu erstellen
